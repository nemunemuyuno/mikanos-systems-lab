# MikanOS Systems Lab

『ゼロからのOS自作入門』のMikanOSを基盤として、
OS内部の理解・独自拡張・性能評価を行う個人プロジェクト。

## Goals

1. MikanOS本編を一周し、全体構造を理解する
2. OS内部の統計・トレース・可観測性を追加する
3. 周期タスク・リアルタイムスケジューリングを実装・評価する

## Progress

- [ ] M0: MikanOS本編
- [ ] M1: Observability / tracing
- [ ] M2: Periodic tasks / RM scheduling
- [ ] M3: Optional extension
